## GitHub Automation Script

- Automated GitHub account registration is not supported; ensure you sign up manually first.
- Generate a personal access token with the `repo` scope and export it before running the script: `export GITHUB_TOKEN=ghp_yourTokenHere`.
- Install dependencies if you have not already: `npm install`.
- Run the interactive helper to scaffold a repository and optional branches: `npm run create:github`.
- Follow the prompts to choose the owner (personal or org), set repo metadata, auto-initialize with a README, and list extra branches to set up quickly.
